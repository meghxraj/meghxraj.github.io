# Megharaj G Mogaveer — Portfolio

A responsive, single-page professional profile for GitHub Pages. The site includes a direct PDF download of the 2026 resume in `assets/`.

Planned site URL: [https://meghxraj.github.io/](https://meghxraj.github.io/)

## Publish with GitHub Pages

1. Create a **public** repository named [`meghxraj.github.io`](https://github.com/meghxraj/meghxraj.github.io).
2. Put the contents of this folder at the repository root, including the `.github/workflows/pages.yml` workflow.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source if it is not selected already.
4. Push the `main` branch. The workflow deploys the site to `https://meghxraj.github.io/`; its run summary shows the deployment status.

The resume PDF is a public download when this site is public. To update it later, replace the file in `assets/` and keep the same filename, or update both resume links in `index.html`.

## Files

- `index.html` — profile content and metadata
- `styles.css` — responsive layout and visual styling
- `assets/Megharaj_G_Mogaveer_Resume_2026.pdf` — downloadable resume
- `.github/workflows/pages.yml` — deployment workflow
